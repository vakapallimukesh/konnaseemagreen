# Konaseema Greens – Custom Plant Gifting Website

A modern, responsive, mobile-first plant gifting web app for **Konaseema Greens**.

## Features
- **Live Gift Preview**: Real-time visual feedback showing selected packaging box, plant variety, custom big label tag, and personal message card.
- **Packaging Styles**: Handcrafted gift boxes including White Window Box, Kalpavriksha Blue Box, Kraft Paper Pot, Temple Diya Box, Celebration Pouch, and Handle Caddy.
- **Plant Varieties**: Popular flowering & green plants (Red Rose, Jasmine Mogra, Red Hibiscus, Sacred Tulasi, Money Plant).
- **Custom Personalization**: Big printed label & custom message note.
- **Event / Bulk Gifting**: Quantity stepper with quick presets (1, 5, 10, 25, 50, 100+).
- **Direct WhatsApp Ordering**: One-tap order enquiry formatted directly to WhatsApp (`+91 77940 22444`) with delivery details and full cost breakdown.

## Tech Stack
- HTML5
- CSS3 (Mobile-first responsive design)
- Vanilla JavaScript

## Deploy on Render
1. Connect this repository to [Render](https://render.com).
2. Choose **Static Site**.
3. Set **Build Command** to empty (or leave default).
4. Set **Publish Directory** to `.`.
5. Deploy!
